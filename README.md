# iaminci/homebrew-tap

Homebrew formulae for [Opsly MD](https://github.com/iaminci/opsly-md) tools.

## Install

```bash
brew install iaminci/tap/opslymd
```

Or tap first, then install by name:

```bash
brew tap iaminci/tap
brew install opslymd
```

## Formulae

| Formula | Description |
|---------|-------------|
| `opslymd` | Render Markdown in the terminal, like `cat` but formatted ([source](https://github.com/iaminci/opslymd-cli)) |

## Releasing a new version

`Formula/opslymd.rb` is generated by GoReleaser. Pushing a `vX.Y.Z` tag to [opslymd-cli](https://github.com/iaminci/opslymd-cli) runs its release workflow, which builds the binaries and commits the updated formula here. Do not edit the formula by hand; change the `brews` section of `.goreleaser.yaml` in `opslymd-cli` instead.

The workflow needs a `HOMEBREW_TAP_TOKEN` secret in `opslymd-cli`: a personal access token with write access to this repository.
